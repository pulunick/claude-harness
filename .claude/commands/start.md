세션을 정해진 순서로 연다. 인자(있으면 오늘 하고 싶은 것): $ARGUMENTS

1. **동기화**: `git pull --rebase --autostash`. 충돌이 나면 강제로 풀지 말고 충돌 파일을 보고하고 멈춘다. 오프라인이면 그 사실을 적고 계속한다.
2. **상황판**: 세션 시작 훅이 이미 `[하네스]` 블록을 찍었으면 그걸 쓰고, 없으면 `python tools/harness/session_start.py`(맥은 `python3`)를 실행한다. 여기서 보는 것 — 내 신원(`who@machine`), 원격과의 차이, 최근 커밋의 `Worked-by`(누가 어디서), 커밋 안 된 변경, 메모리 링크 상태.
   - 커밋 안 된 변경이 있으면 상대 기기에서 넘어온 게 아니라 **이 기기의 지난 세션이 `/wrap` 없이 끝난 것**이다. 내용을 보고 먼저 정리할지 묻는다.
   - 메모리가 "홈 링크 없음"이면 `.claude/memory/MEMORY.md`를 읽고, 관련 항목 본문만 꺼내 읽는다.
   - "📨 내게 온 이슈"가 있으면 오늘 할 일 후보 맨 앞에 둔다(`/issue list`).
   - 상황판에 ⚠가 있거나 이 기기의 첫 세션이면 `python tools/harness/doctor.py`로 설치·규약을 점검하고 FAIL은 먼저 고친다.
3. **문서**: `.claude/BRAIN.md`(확정) → `.claude/STATE.md`(진행) 순서로 읽는다.
4. **인수인계 요약** 3~5줄: 상대(또는 지난 세션의 나)가 마지막으로 한 것 / STATE에서 내 담당(`[이름]`·`[누구나]`)으로 열린 것 / 결정 대기 중 내가 답할 수 있는 것.
5. **오늘 할 일**: 선택지 2~3개 + 추천 1개로 묻는다. 인자가 있으면 그걸 1순위로 두고 STATE와 충돌하는지만 확인한다.
6. 작업을 잡으면 STATE 해당 항목 앞에 내 이름을 적는다(아직 커밋하지 않아도 된다 — `/wrap`이 함께 커밋한다).
