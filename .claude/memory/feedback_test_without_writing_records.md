누르는 순간 덧붙이기 전용 기록(판정·요청 이력 등)에 줄이 남는 기능은, 확인할 때 실제 자료에서 누르지 않는다. 대신
1. 자료를 임시 폴더에 복사하고 다른 포트로 서버를 띄운 **복사본 환경**에서 끝까지 돌리거나
2. 브라우저 안에서 화면 상태만 임시로 바꿔(서버에 보내지 않고) 표시를 확인한다.
무엇을 눌러 보지 않았는지는 보고에 적는다. 복사본 환경은 다 쓰면 지운다.

**Why:** 시험 흔적이 사용자의 실제 이력에 섞이면 되돌릴 방법이 없다. 2026-11-11 한 프로젝트에서 요청 기능을 복사본 + 다른 포트로 끝까지 확인하다가, 같은 초에 요청 두 개면 번호가 겹치는 문제도 거기서 찾았다.
**How to apply:** 기록·요청을 만드는 화면 기능을 새로 만들거나 고쳤을 때. 관련: [[feedback_dont_reload_users_tab]]
