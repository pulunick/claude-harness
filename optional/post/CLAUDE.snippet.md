## SNS 게시물 프로젝트 (post 모듈)

- 게시물 하나 = `docs/01_게시물/YYYY-MM-DD_<슬러그>/post.md` — 글 본문·영상 캡션·다른 채널판·쓴 영상/이미지 경로·게시 결과를 한 파일에. 틀은 `docs/01_게시물/_틀.md`. 아이디어는 `docs/02_아이디어/backlog.md`에 쌓고, 쓰면 게시물 폴더로 옮긴다.
- 문서는 `docs/00_채널(말투·브랜드) · 01_게시물 · 02_아이디어 · 03_편집`. 루트에 새 문서가 생기면 `docs/` 아래로 옮긴다(루트엔 CLAUDE.md만).
- 영상 규격: 세로 **1080×1920 30fps**, 15~30초, **자막 필수**(무음 시청 전제), 첫 1초에 화면이 움직이게. 자막 틀(폰트·크기·위치·색)은 확정되면 여기에.
- `media/원본/`은 어떤 경우에도 수정·삭제하지 않는다(접두어 `YYYYMMDD_<슬러그>_`). 편집 프로젝트는 `edit/film|effect|motion/`, 결과물은 `media/내보내기/영상|이미지|썸네일/`. 편집은 작은 단위로 → 보여주고(`open`) → 승인.
- 이미지 생성: 후보 `edit/<종류>/candidates/`(커밋 제외) → 확정 `media/내보내기/이미지/`, 프롬프트 기록 `edit/<종류>/prompts.md`. 생성 영상·유료 생성은 사용자 승인 뒤에만.
- 발행은 수동(복붙 체크리스트) — 게시하면 post.md "게시 결과"에 시각·링크, 1주 뒤 반응 메모.
- 크래프트 앱 MCP는 `.mcp.json`(기본 headless, 파일 접근은 이 폴더로 제한). 라이브 앱이 필요하면 `--bridge <포트>`를 `.mcp.json`에 적고 `tools/craft.sh film|effect|vector`로 연다(포트는 다른 프로젝트와 겹치지 않게).
- 공통 절차는 전역 스킬: `craft`(크래프트 앱) · `codex-image`(그림 생성) · `video-edit`(영상 편집) · `hyperframes`(HTML → 영상, 자막·타이틀).
